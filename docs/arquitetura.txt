## 2. COMPONENTES E FUNÇÕES

| Componente | Papel | Tecnologia | Porta |

**Snapshot `forms_denuncia/celery.py`:**
```python
import os
from celery import Celery

os.environ.setdefault('DJANGO_SETTINGS_MODULE', 'forms_denuncia.settings')
app = Celery('forms_denuncia')
app.config_from_object('django.conf:settings', namespace='CELERY')
app.autodiscover_tasks()

# Confiabilidade
app.conf.task_acks_late = True
app.conf.task_reject_on_worker_lost = True
app.conf.worker_prefetch_multiplier = 1
```

**Snapshot `core/tasks.py`:**
```python
@shared_task
def limpar_exif_imagem(evidencia_id):
    try:
        evidencia = Evidencia.objects.get(id=evidencia_id)
        img = Image.open(evidencia.imagem.path)
        dados_pixel = list(img.getdata())
        imagem_limpa = Image.new(img.mode, img.size)
        imagem_limpa.putdata(dados_pixel)
        imagem_limpa.save(evidencia.imagem.path)
        return f"SUCESSO: EXIF limpo para evidência #{evidencia_id}"
    except Evidencia.DoesNotExist:
        return f"Erro: Evidência #{evidencia_id} não encontrada."
    except Exception as e:
        return f"Erro ao processar imagem: {str(e)}"
```

## 7. FLUXO DE REQUISIÇÃO (ENVIO DE DENÚNCIA COM FOTO)

```
Usuário → Nginx (futuro) → Gunicorn (Web) → Django View
    │
    ├─ Salva Denuncia + Evidencia no Postgres
    ├─ Retorna HTTP 302 (protocolo) IMEDIATAMENTE
    └─ Enfileira `limpar_exif_imagem.delay(id)` no Redis (Broker)
                          │
                          ▼
              Celery Worker pega da fila
                          │
                          ▼
              Abre imagem → Remove EXIF → Sobrescreve arquivo
                          │
                          ▼
              Guarda resultado no Redis (Result Backend)
                          │
                          ▼
              Flower mostra: SUCCESS, tempo, worker, args
```

## 8. PRÓXIMOS PASSOS NATURAIS

1. **Nginx Reverse Proxy** + TLS (Let's Encrypt) na frente do Gunicorn
2. **Backup automatizado** do volume `postgres_data` e `media_volume`
3. **Logs centralizados** (Loki/ELK) via `logging` config no Django
4. **Testes automatizados** no pipeline (pytest + coverage)
5. **Tarefas periódicas reais** no Beat (ex: limpeza de sessões expiradas, relatórios)
